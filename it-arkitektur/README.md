# IT-arkitektur

Velkommen til faget **IT-arkitektur**. Her arbejder vi med, hvordan man designer systemer, der er
til at forstå, vedligeholde og skalere.

## Læringsmål

- Forklare centrale arkitekturbegreber og kvalitetsattributter
- Vælge og begrunde arkitekturmønstre til en given problemstilling
- Dokumentere en arkitektur med diagrammer (fx C4-modellen)
