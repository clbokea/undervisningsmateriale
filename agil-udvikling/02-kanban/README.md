# 02 – Kanban

Kanban handler om at visualisere arbejdet og begrænse *work in progress* (WIP).

## Principper

1. Visualisér flowet
2. Begræns WIP
3. Mål og optimér flow (lead time, cycle time)

## Øvelse

Opret et Kanban-board i GitHub Projects med kolonnerne **To do**, **In progress** (WIP 3) og **Done**.
