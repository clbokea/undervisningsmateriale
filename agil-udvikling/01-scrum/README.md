# 01 – Scrum

## Roller

- **Product Owner** – ejer backloggen og prioriterer
- **Scrum Master** – fjerner forhindringer og coacher teamet
- **Developers** – leverer et færdigt inkrement hvert sprint

## Events

| Event | Varighed (2-ugers sprint) |
|-------|---------------------------|
| Sprint Planning | 4 timer |
| Daily Scrum | 15 min |
| Sprint Review | 2 timer |
| Retrospective | 1,5 time |

## Øvelse

Skriv fem user stories på formen *“Som … vil jeg … så …”* til jeres semesterprojekt.
